# 암호를 함수로 읽다

고등학교 공통수학2 「함수와 그래프」 2차시 수업용 웹앱입니다.
카이사르 암호부터 해시까지를 **정의역·치역·일대일대응·합성함수·역함수**로 다룹니다.

## GitHub Pages 배포 방법

1. GitHub에서 새 저장소를 만듭니다. (Public)
2. `index.html`, `.nojekyll`, `README.md` 세 파일을 올립니다.
3. 저장소 → **Settings → Pages**로 갑니다.
4. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `/ (root)`로 지정하고 저장합니다.
5. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다.

`.nojekyll` 파일은 GitHub가 파일을 임의로 가공하지 않게 하는 빈 파일입니다. 지우지 마세요.

## 주의: 반드시 https 주소로 접속

SHA-256과 AES는 브라우저에 내장된 Web Crypto를 사용합니다.
이 기능은 보안 연결에서만 동작하므로, `index.html`을 바탕화면에서 더블클릭해 열면
해당 두 화면만 동작하지 않습니다. GitHub Pages 주소(https)로 접속하면 정상 동작합니다.
나머지 화면은 인터넷 없이도 모두 동작합니다.

## 화면 구성

번호는 수업 진행 순서입니다. 주소창에 `#caesar` 처럼 붙이면 해당 화면으로 바로 열립니다.

| | 화면 | 수업 장면 |
|---|---|---|
| 01 | 기둥에 감는 암호 | 1차시 도입 · 정의역이 글자가 아니라 자리 |
| 02 | 카이사르 암호 | 1차시 전개 1~2 · 도전 문제, 단계별 합성, 역함수 |
| 03 | 아핀 암호와 일대일대응 | 1차시 전개 3 · a=13에서 화살표가 두 점으로 몰림 |
| 04 | 단일치환과 빈도분석 | 2차시 도입~전개 1 · 식 없는 함수, 빈도 보존 |
| 05 | 비즈네르 암호 | 2차시 전개 2 · 정의역을 순서쌍으로 확장 |
| 06 | RSA | 2차시 전개 3 · 역함수는 있지만 못 구함 |
| 07 | 해시 | 2차시 전개 4 · 일대일이 아니라서 강함 |
| 08 | AES (심화) | 합성의 역순 · 시간이 남을 때만 |
| 09 | 세 층으로 정리하기 | 2차시 정리 |

## 카이사르 도전 화면 사용법

1. 교사가 맨 위 **교사용** 칸을 펼치고 원문과 시프트를 입력합니다. 입력하는 동안 화면에는 ●로 가려집니다.
2. **암호문 내보내기**를 누르면 교사용 칸이 접히고 암호문만 크게 표시됩니다.
3. 학생이 앞에 나와 아래 칸에 원문을 입력합니다. 이 칸은 가려지지 않으므로 반 전체가 함께 봅니다.
4. 맞히면 축하 효과와 함께 규칙이 함수식으로 공개됩니다.
5. **힌트**는 첫 세 글자를, **25가지 다 해보기**는 전수조사 결과를 보여 줍니다.

**정답 공개** 버튼은 시간이 부족할 때 교사가 바로 넘어가기 위한 것입니다.

## 원본 코랩 코드에서 고친 점

- **나머지 연산**: 파이썬 `%`는 음수에서도 양수를 돌려주지만 자바스크립트는 그렇지 않아 복호화가 깨집니다.
  나머지 함수 `r(x)`를 따로 정의해 사용했습니다. 수업에서 약속한 그 함수와 같습니다.
- **비즈네르 키 진행**: 원본은 공백과 문장부호에서도 키가 넘어갔습니다.
  정의역을 (글자, 몇 번째 글자)로 잡기로 했으므로 알파벳일 때만 진행하도록 고쳤습니다.
- **단일치환 복호화**: 계산해 놓고 쓰지 않은 변수를 정리하고, 역대응표를 미리 만들어 씁니다.
  키가 26글자 순열이 아니면 예외를 던지던 부분에 검사를 붙였습니다.
- **AES**: `Fernet`은 AES 자체가 아니라 AES-CBC와 HMAC을 묶은 것입니다. 브라우저 내장 AES-GCM으로 바꿨습니다.
- **RSA**: 2048비트 키는 학생이 손으로 확인할 수 없어, 소수를 직접 고르고 거듭제곱의 나머지를
  한 줄씩 따라갈 수 있는 작은 수 버전으로 바꿨습니다.
- **SHA-256**: `hashlib` 대신 브라우저 내장 Web Crypto를 씁니다.

## 알파벳 대응 약속

`A = 0, B = 1, …, Z = 25` 이며, `r(x)`는 x를 26으로 나눈 나머지입니다.
